1. ⌂ Home

استعرض مهام اليوم ومجموع النقاط وملخص الحالات ورسوم الإنجازات.

2. 🎖 Add Task

تعرّف على حقول توثيق الإنجاز والتصنيف والأولوية والملفات الداعمة.

3. ▤ Calendar

تابع سجل الإنجازات حسب التاريخ وافتح تفاصيل المهام من التقويم.

4. ★ Reward

راجع إنجازات فريقك وامنح نقاط التميز، أو أعد المهمة للمراجعة أو ارفضها.

5. ＋ Assign Task

أسند مهام لأعضاء فريقك وحدد التصنيف والأولوية والنوع والملفات.

6. ☰ View Enjazaty

استعرض مهامك ومهام فريقك مع العدادات وخيارات البحث والتصفية.

7. ⚙ Settings

أضف مشاريع جديدة وعدّل بيانات المشاريع أو احذفها.
